# requirements.txt — server/inference/face_recognition.py

# Curated, commented list of DIRECT dependencies — read this to understand
# *why* something is pinned. `make install` does not install from this file
# directly; it installs from requirements-lock.txt (a full pip-freeze
# snapshot of this exact set, direct + transitive, proven working). If you
# add/remove/change a dependency here, regenerate the lock afterward with
# `make freeze` and commit both files together.
#
# Pinned GPU stack. Requires Python 3.11+ (proven on 3.13.11, Linux x86_64,
# NVIDIA RTX 3090, driver 580.159.03).
#
# Install (recommended):
#   make install
#   make install PYTHON="py -3.13"    # Windows: pick a 3.11+ interpreter
#
# ⚠️ CRITICAL — torch MUST be the CUDA-12 build (+cu126), NOT the PyPI default.
#   YOLO (torch) and InsightFace (onnxruntime-gpu) run in ONE process and share
#   cuDNN/NCCL. onnxruntime-gpu is built for CUDA 12, so torch must also be CUDA 12.
#   The default `pip install torch` pulls a CUDA-13 build whose cuDNN/NCCL collide
#   with onnxruntime-gpu's (CUDNN_STATUS_SUBLIBRARY_VERSION_MISMATCH /
#   "undefined symbol: ncclCommResume"). The --extra-index-url below fixes this.
#
# NVIDIA CUDA/cuDNN/NCCL runtime libraries are pulled in automatically as wheels
# by torch and onnxruntime-gpu — no system CUDA toolkit install is required.
#
# ⚠️ onnxruntime / onnxruntime-gpu share the same import namespace (`onnxruntime`)
#   and silently overwrite each other's files if both get installed. insightface
#   declares a hard dependency on plain `onnxruntime`, so a naive `pip install`
#   of this file WILL pull the CPU-only package back in after onnxruntime-gpu is
#   installed, and whichever installs last wins (all inference silently falls
#   back to CPUExecutionProvider with no error). `make install` handles this by
#   uninstalling `onnxruntime` and force-reinstalling `onnxruntime-gpu` last —
#   don't `pip install -r requirements-lock.txt` on its own and expect the GPU
#   build to stick; use `make install`.
#
# --- System prerequisites (not pip-installable, verify separately) ----------
#   ffmpeg 6.1.1+ with NVDEC/cuvid decoders (h264_cuvid, hevc_cuvid, ...) —
#     check via `ffmpeg -decoders | grep cuvid`
#   NVIDIA driver 580.159.03+ (CUDA 13.0 driver API; wheels below target the
#     CUDA 12.6 runtime, which that driver version supports)
#   Node.js — see web/.nvmrc / web/package.json "engines" for the pinned
#     frontend toolchain version
# =============================================================================
